Personal radio / prototype

Verify the music.
Then build the player.

This local tool checks your accounts and full-length FLAC access. The Windows and Android Flutter application is gated on successful integration checks. Recap inclusion remains unverified.

1. Connect YouTube Music

In your signed-in YouTube Music tab, copy the request headers from a successful /browse POST request using the Network panel in developer tools. See the ytmusicapi instructions.

2. Connect Tidal with PKCE

Sign in with your subscribed Tidal account. After login, copy the entire final redirect URL from the “Oops” page and paste it below.

3. Check recommendations



Autoplay starts with the selected song and adds YouTube's automatic suggestions. Start radio creates a mix immediately. Load more continues the same Autoplay queue.






4. Verify full-length source audio
Enter a Tidal recording ID. Run one standard lossless test and one Hi-Res test. The source is read through the authenticated proxy and fully decoded to a null sink. No audio file is retained, and decoder checks never submit listening activity.





Audible playback and accurately measured history submission are checked separately with the listen command in the README. Full-source decoding alone does not pass the playback gate.
